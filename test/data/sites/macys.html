My new favorite pan - Ol' Faithful

This is the first time I have used a stainless steel pan - I've only ever used nonstick and I will NEVER go back!!!!!!!! This pan is absolutely amazing!!!!! The size is perfect (large enough to fit pretty much anything, but not so big that it's awkward). There's definitely a learning curve if you've been using nonstick only (i.e. warm the pan on med-low, drop water and if it dances/bubbles the pan is ready, then add oil/butter, adjust heat as needed, if food is sticking then you need to WAIT because it's not don yet). Now that I've got the learning curve down, this is HANDS DOWN my all-time favorite pan that I've used in my 10+ years of cooking. I bought some Barkeepers Friend to give it a good shine every now and then - but honestly, the markings from cooking give it character, and the pan gets "seasoned" every time I use it. This pan lets flavors shine through on their own in a way that I've never tasted before, and the searing is a thing of beauty. I love, love, love this pan so much! I named it Ol' Faithful :)
